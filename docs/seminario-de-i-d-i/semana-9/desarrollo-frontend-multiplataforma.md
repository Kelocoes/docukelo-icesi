# Desarrollo frontend multiplataforma

El desarrollo frontend multiplataforma permite construir interfaces de usuario de alto rendimiento a partir de una única base de código capaz de desplegarse en dispositivos móviles (Android / iOS), web y escritorio.

---

## Conceptos clave

* **Base de código unificada**: Reducción de duplicidad en la lógica de negocio y componentes visuales.
* **Paradigma declarativo**: La interfaz de usuario se define como una función directa del estado de la aplicación ($UI = f(state)$).
* **Renderizado propio vs. componentes nativos**: Comprensión del modelo de renderizado por lienzo (*canvas*) frente al puente nativo (*native bridge*).
