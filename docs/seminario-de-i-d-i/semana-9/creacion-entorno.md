# Creación de entorno

Guía para la instalación, configuración y verificación de herramientas necesarias para el desarrollo multiplataforma y la asistencia por IA en consola.

---

## Herramientas requeridas

* **SDK de Flutter**: Kit de herramientas de desarrollo multiplataforma.
* **Editor de código**: VS Code con extensiones recomendadas (Flutter, Dart, Claude/Gemini CLI).
* **Emulador / Dispositivo de prueba**: Android Studio Virtual Device (AVD), simulador de iOS o dispositivo físico con depuración activa.
* **Entorno Cloud**: Cuenta y configuración inicial del proyecto en Supabase.
