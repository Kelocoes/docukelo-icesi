# Docker Setup

## Installation and Configuration

### Windows
- Install Docker Desktop with WSL2 backend enabled.
- Verify installation with `docker --version`.

### macOS
- Install Docker Desktop for Mac (Apple Silicon / Intel).

### Linux
- Install `docker.io` or official Docker Engine packages.
- Add user to `docker` group to run commands without `sudo`.
