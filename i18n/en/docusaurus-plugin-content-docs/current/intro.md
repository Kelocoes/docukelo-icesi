## How to use this site

- **Follow the order of the weeks.** Each course is organized into weeks, and within each week the documents are numbered in the order in which they are best read.
- **Mark what you have read.** In the side menu, the checkbox next to each page marks it as read. Your progress in each course shows up on these cards and is stored only in your browser.
- **Find what you need.** Use the search box in the top bar or the `Ctrl+K` shortcut.
- **Focus while you study.** The *Focus Mode* button hides the menu so the content takes the full width, and the switch in the top bar toggles between light and dark themes.
- **Choose your language.** Many documents have an English version; those that do not yet are shown in Spanish.
- **Make the most of the code.** Every code block shows the file it belongs to and has a button to copy it.
